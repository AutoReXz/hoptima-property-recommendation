# HOPTIMA — Property Recommendation System

## Project Overview and Background

HOPTIMA is a Bangkit Academy 2024 capstone for property discovery in Yogyakarta. A seven-member team worked across Machine Learning, Cloud Computing, and Mobile Development.

## Problem and Objectives

Property seekers can spend time comparing listings across locations, budgets, and features. The project explored how a recommendation application could use stated preferences to narrow those options and present suitable properties through a mobile interface.

## My Role and Contributions

I was a Machine Learning cohort member. I contributed to cleaning and preprocessing property data, exploring its attributes, preparing features, and developing and evaluating a recommendation model. I also coordinated with the Cloud Computing and Mobile Development tracks and supported model integration into the application.

## Technologies and Workflow

The machine learning work used Python and TensorFlow. The workflow moved from data cleaning and exploratory analysis to feature preparation, model development and evaluation, and integration with the cloud and mobile components.

## Model Development and Evaluation

The experimentation notebook includes separate numeric and text model artifacts. It uses feature scaling, TF-IDF text features, and a train/test split. The notebook computes mean absolute error, mean squared error, and R² as part of its evaluation. Training and prediction plots document the experiments.
